Interactive IT & CS Quiz App 

A simple and responsive quiz application built using HTML, CSS, and JavaScript.
This project features an engaging UI, smooth transitions, a progress bar, and real-time scoring.
The quiz includes IT & Computer Science–related MCQs, making it ideal for students, beginners, and anyone wanting to test their tech knowledge.

🚀 Live Demo :

https://maznu007.github.io/quizgame/

📌 Features :


🎮 Interactive Quiz Experience
Start, answer questions, view results, and restart anytime.

📊 Dynamic Progress Bar
Updates after every question.

🧠 10 Multiple-Choice Questions
Focused on IT & CS fundamentals.

✔️ Instant Answer Feedback
Correct answers highlight in green; wrong in red.

⭐ Smart Result Evaluation
Custom messages based on performance.

📱 Fully Responsive Design
Clean modern UI with custom color theme.


🛠️ Tech Stack :


HTML5	Structure

CSS3	Custom styling & UI

JavaScript (ES6)	Quiz logic & interactivity

📂 Project Structure :
/quiz-app

│── index.html

│── style.css

│── script.js

│── README.md

⚙️ How It Works :

User clicks Start Quiz

Questions load one by one

User selects an answer

Progress bar updates

After all 10 questions → Result Screen

User can restart the quiz
